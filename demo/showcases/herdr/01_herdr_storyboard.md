# wayhint 紹介動画 シナリオ（初稿）

- 形式: 画面録画 + 字幕のみ（無音 or BGM）。ナレーション無し
- 3 本とも同じ素材から切り出せる構成にしてある。**5 分版を撮り、そこから 2〜3 分版・60 秒版を編集で作る**のが最短
- 主役の 3 場面（毎回この順で出す）
  1. **Herdr の中の Claude Code まで見て自動で切り替わる**
  2. **focus を奪わないので、出したまま作業を続けられる**
  3. **忘れた操作をその場で追記して育てる**
- 表記: hotkey は実機の割り当て `Super+H`（toggle）/ `Super+Ctrl+H`（編集モード）に合わせる。設計書の `Super+?` は使わない

### 環境

- 録画は自分専用の headless compositor の中で行う。いま使っているセッションには触らない
- 映すアプリ: Herdr + Claude Code / Codex の stub、foot 単体 + vi の stub
- **映さない**: 実コード、会話内容、ホームパスに含まれるユーザー名
- Claude Code / Codex は起動直後の待ち受け画面で止める(stub なので会話は起きない)

### hint sheet(`demo/fixtures/hints/ja/`)

- `herdr.yaml` — pane 操作 4 件。うち 3 件に `tags: [terminal]`。`favorite` は無し(★ が付くと Herdr の hint が先頭へ出てしまい、「後ろに続く」が成立しない)
- `claude-code.yaml` — 5 件。`inherit: {parent_tags: [terminal]}`。1 件に `remark`、1 件 `favorite`
- `codex.yaml` — 3 件(切替が「Claude Code 専用」でないと示す用)。`favorite` は無し——5 分版が `f` で ★ を付けて見せるので、先頭行は素の hint でなければならない
- `notes.yaml` — 7 件。`match.wayland` で GUI stub の app_id に当てる(5 分版のみ)。`vi.yaml` は §6 の YAML を開く場面で使う
- `wm.yaml` — `match` 無し、2 件。`config.yaml` に `include: [wm]`
- 撮影中に追記する hint は「直前の検索を繰り返す / `n`」。Codex の sheet に入る

## 3. 5 分版(YouTube 解説)
<!-- variant: 5min -->

2〜3 分版の §1–§6 をそのまま使い、間に「仕組み」と「設定」を差し込む。合計 258 秒。
差分だけを挙げる(それ以外は 2〜3 分版と同じ字幕・同じ順)。§5 だけは中の順序も変わる——
単キー操作(`J` / `K` / `f`)はフォームの**前**に入る。フォームの保存が編集モードを終える
仕様(DECISIONS 0021)なので、保存の後に単キーを押しても overlay には届かない。

### §3 に追加: GUI アプリでも同じ(0:58–1:32)

§3 の裏返し。端末は**中で動いているプロセス**で選ばれ、GUI アプリには覗き込むプロセスが無いので
**窓の app_id** で選ばれる(DECISIONS 0024)。映すのは demo の GTK4 stub `notes` で、実アプリは
使わない。窓は下の端末を覆う大きさにしてある——この場面の主語は GUI の窓なので、後ろに端末が
覗いていると何を見ればいいのか分からなくなる。overlay の sub-header にプロセス名が出ず `dev.wayhint.demo.Notes` だけが出るのが要点。

| 秒 | 画面 | 字幕 |

| 58–63 | GUI アプリ(Notes)が開く。Herdr の窓は隠れる | GUI アプリでも同じ |
| 63–72 | `Super+H` → `Notes` の sheet。sub-header は app_id だけ | 端末は中のプロセス、GUI は窓の app_id |
| 72–81 | 同じ画面。一覧の末尾に wm の hint | 窓の操作はどの sheet にも付いてくる |
| 81–92 | overlay を閉じ、Notes の窓も閉じて Herdr に戻り、`Super+H` で出し直す | (字幕なし) |

### §5 に追加: 並べ替えと favorite(2:18–2:37、フォームの前)

編集モードに入った直後、フォームを開く前に入る。動かせるのは**カーソルのある行**、つまり
先頭行——編集モードには選択行を動かすキーが無い(実測)。以降の秒は §5 全体がここのぶんだけ
後ろへずれる(フォームは 2:37 から、保存は 2:49、YAML を壊すのは 2:56)。

| 145.5–149.5 | `K` → 戻る | (字幕なし) |
| 149.5–157.5 | `f` → 先頭行に ★ が付く | f で ★ を付け外し。★ は先頭にまとまる |

その行にあり、言語は status 行の `"hints/ja/claude-code.yaml"` に出る。

| 196.1–203.1 | vi で `hints/ja/claude-code.yaml` を開く | sheet は 1 アプリ 1 YAML |

## 4. 字幕の書き方メモ

- 1 枚 20 文字前後、2 行まで。動作が起きる **直前** に出して、動作中は消さない
- hotkey と CLI は等幅で `Super+H` `wayhint context` のように表記
- 「主役」3 場面の見出し字幕は 3 本で同じ文言にする（切り出しても揃う）:
  - 「見ているのは窓ではなく、端末の中で動いているもの」(60 秒版。2〜3 分版と 5 分版は
    同じ場面を「見ているのは窓ではなく、中のプロセス」と書く。**画面が切り替わるのは
    この字幕の 3 場面あと**なので、どちらも状態の説明にしてある)
  - 「出したまま、そのまま作業できる」
  - 「忘れた操作は、その場で追記」
- 英語版が要る場合はこの 3 枚と締めの原則文を先に訳し、他は後回しでよい
