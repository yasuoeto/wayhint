# wayhint 紹介動画 シナリオ（初稿）

- 形式: 画面録画 + 字幕のみ（無音 or BGM）。ナレーション無し
- 3 本とも同じ素材から切り出せる構成にしてある。**5 分版を撮り、そこから 2〜3 分版・60 秒版を編集で作る**のが最短
- 主役の 3 場面（毎回この順で出す）
  1. **Herdr の中の Claude Code まで見て自動で切り替わる**
  2. **focus を奪わないので、出したまま作業を続けられる**
  3. **忘れた操作をその場で追記して育てる**
- 表記: hotkey は実機の割り当て `Super+H`（toggle）/ `Super+Ctrl+H`（編集モード）に合わせる。設計書の `Super+?` は使わない

### 環境

- 録画は自分専用の headless compositor の中で行う。いま使っているセッションには触らない
- 映すアプリ: Herdr + Claude Code / Codex の stub、foot 単体 + vi の stub
- **映さない**: 実コード、会話内容、ホームパスに含まれるユーザー名
- Claude Code / Codex は起動直後の待ち受け画面で止める(stub なので会話は起きない)

### hint sheet(`demo/fixtures/hints/ja/`)

- `herdr.yaml` — pane 操作 4 件。うち 3 件に `tags: [terminal]`、1 件 `favorite: true`
- `claude-code.yaml` — 5 件。`inherit: {parent_tags: [terminal]}`。1 件に `remark`、1 件 `favorite`
- `codex.yaml` — 3 件(切替が「Claude Code 専用」でないと示す用)。1 件 `favorite`
- `vi.yaml` — 3 件(Herdr 無しでも foreground process を見る、を示す用。5 分版のみ)
- `wm.yaml` — `match` 無し、2 件。`config.yaml` に `include: [wm]`
- 撮影中に追記する hint は「直前の検索を繰り返す / `n`」。Codex の sheet に入る

## 4. 字幕の書き方メモ

- 1 枚 20 文字前後、2 行まで。動作が起きる **直前** に出して、動作中は消さない
- hotkey と CLI は等幅で `Super+H` `wayhint context` のように表記
- 「主役」3 場面の見出し字幕は 3 本で同じ文言にする（切り出しても揃う）:
  - 「端末の中で動いてるものまで見て切り替わる」
  - 「出したまま、そのまま作業できる」
  - 「忘れた操作は、その場で追記」
- 英語版が要る場合はこの 3 枚と締めの原則文を先に訳し、他は後回しでよい
