# all — wayhint をひととおり見せる

- 形式: 画面録画 + 字幕のみ（無音 or BGM）。ナレーション無し
- `common` の 4 本(overview / search / edit / sheets)の共通動作と、見つけ方 3 本(`herdr` /
  `terminal` / `gui`)のアプリの種類ごとの場面を 1 本にまとめる(DECISIONS 0043)
- 尺の違う **3 つの variant**(`60s` / `180s` / `300s`)を持つ。どれも clean session から撮る完全な
  1 本で、長い版から切り出さない(DECISIONS 0032)。同じ操作でも尺が違えば別の step にする
  (脚本の `m-` は 180 秒用、`q-` は 60 秒用)
- 場面と字幕は元の 4 本で見直したものを写す。**字幕を直すときは元の showcase の側も直す**
  (同じ場面は同じ文言。`demo/README.md`「字幕の書き方」7・8)
- 主役の 3 場面（この順で出す）: 一番前のプロセス、出したまま入力できる、その場で書く

---

## 0. 撮影前の準備

> `./scripts/demo --showcase all --record` で 3 本とも生成する。下の表の秒と字幕は生成物と同期して
> ある(`--validate` が見る)。

- session は Herdr あり。1 本の中で Herdr・端末・GUI の窓を開いては閉じる
- 状態は章をまたいで引き継ぐ: 主役 3 で足したヒントで Claude Code の一覧は以後 16 件になる。
  見つけ方: Herdr の章で絞った `herdr.yaml` は、章の終わりに fixture に戻す
- 映すアプリ、stub、壊す・絞る YAML は元の showcase と同じ(`common/broken/`、`herdr/narrowed/`)
- **映さない**: 実コード、会話内容、ホームパスに含まれるユーザー名
