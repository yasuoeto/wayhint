# common — wayhint で何ができるか

[English](01_common_storyboard.md)

- 形式: 画面録画 + 字幕のみ（無音 or BGM）。ナレーション無し
- **4 本のうちの 1 本**。この showcase は製品の共通機能だけを扱い、context の**見つけ方**は
  `herdr` / `terminal` / `gui` の 3 本が経路ごとに受け持つ
- 中身で分けた **4 つの variant** を持つ(DECISIONS 0042)。どれも単独で見られる 1 本で、Herdr と
  Claude Code の起動から始まる。尺違いの variant(同じ中身の短い版)は持たない
  - `overview` — 何のための道具か、いつも同じ場所、中まで見て切り替わる(主役 1)
  - `search` — 奪わない、検索してコピー(主役 2)
  - `edit` — その場で書く、壊しても復帰(主役 3)
  - `sheets` — シートの書き方、やらないこと
- 全体を通した 1 本は、今後 `demo/showcases/all/` で作る(未着手)。この 4 つの共通動作と、見つけ方 3 本の
  アプリの種類ごとの場面をまとめたものにする
- 主役の 3 場面（この順で出す）
  1. **端末の中で動いているものまで見て自動で切り替わる**
  2. **focus を奪わないので、出したまま作業を続けられる**
  3. **忘れた操作をその場で追記して育てる**
- 表記: hotkey は実機の割り当て `Super+H`（toggle）/ `Super+Ctrl+H`（編集モード）/
  `Super+Shift+H`（検索モード）に合わせる

---

## 0. 撮影前の準備

> 手で録るのではなく、隣の `02_common_scenario.yaml` から
> `./scripts/demo --showcase common --record` で生成する（DECISIONS 0032）。hint sheet は
> `demo/fixtures/hints/ja/`、端末と Herdr の設定は `demo/fixtures/` と `tools/demo/session.py`、
> 録画は headless の compositor の中。**下の表の秒と字幕は、実際に生成されるものと同期して
> ある**（同期を保つのは人。`demo/README.md`「字幕の書き方」9）。撮れない演出（ブラウザ、ズーム、マウス操作、ロゴ画面）は
> `demo/README.md` の「台本から落とした場面」に理由付きで並べてある。

### 環境

- 録画は自分専用の headless compositor の中で行う。いま使っているセッションには触らない
- 映すアプリ: Herdr + Claude Code / Codex の stub、vi の stub
- **映さない**: 実コード、会話内容、ホームパスに含まれるユーザー名
- Claude Code / Codex は起動直後の待ち受け画面で止める（stub なので会話は起きない）

### なぜ Herdr の中で撮るのか

この showcase の主語は**共通機能**で、Herdr はその舞台にすぎない。それでも舞台を 1 つ選ぶ必要が
あり、pane を切り替えるだけで「中で動いているもの」が変わる Herdr がいちばん短く見せられる。
どうやってそこまで辿り着いているか——Herdr に聞く、`/proc` を読む、app_id で選ぶ——は
`herdr` / `terminal` / `gui` の 3 本の仕事で、ここでは説明しない。

### hint sheet（`demo/fixtures/hints/ja/`）

- `herdr.yaml` / `claude-code.yaml` / `codex.yaml` — 実機の `~/.config/wayhint/hints/ja/` の写し
  (2026-09-24)。例外は `claude-code.yaml` 1 行目の英語のコメントで、sheets の vi に映るので写しからは消した。Herdr 6 件、Claude Code 7 件、Codex 1 件。tag の絞りは
  どこにも書いていないので、子の一覧には Herdr の hint が全部混ざる(DECISIONS 0034)。`favorite` は
  無いので ★ は出ない
- `wm.yaml` — `match` 無し、2 件。`config.yaml` に `include: [wm]`
- `vi.yaml` — sheets で YAML を開く場面のもの。`notes.yaml` / `less.yaml` は他の showcase が使う
- 撮影中に追記する hint は「権限モードを切り替える / `Shift+Tab`」(edit)。選択中の Claude Code の hint の隣、
  つまり Claude Code の sheet に入る

## 2. 字幕の書き方メモ

規約は `demo/README.md`「字幕の書き方」が正。ここで守るのはその 7 番——主役 3 場面の見出し字幕で、
他の showcase が同じ場面に触れるときも同じ文言を使う。

- 見ているのはウィンドウではなく、一番前のプロセス
- ヒント画面を出したまま、そのまま入力できる
- 忘れていた操作を見つけたら、その場で書く
